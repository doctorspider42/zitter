# Logos

`zitter.svg` — ikona aplikacji `|z⟩` (ket z), wielokolorowa: ciemny fiolet z gradientem, biała litera z, fioletowy (#8B83FF) nawias ⟩. Używaj w całości jako ikony aplikacji, w O programie i na ekranie startowym; nie przerysowuj, nie przekolorowuj, nie kładź na `zing`. Brak osobnego znaku słownego: nazwę „Zitter” składaj krojem `display` kursywą.
