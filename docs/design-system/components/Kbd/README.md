# Kbd

Klawisz skrótu w `url` (JetBrains Mono 11 px) na `bg-hover` z dolną krawędzią `line`.

**Daje konsument:** jeden symbol na `<kbd class="zt-kbd">`; akord to kilka `zt-kbd` w `zt-keys`.

- Symbole macOS: ⌘ ⌥ ⇧ ⌃ ↵ ⌫ ↑ ↓; słowa małymi literami: `esc`, `tab`.
- W menu kontekstowym klawisz traci tło (`.zt-menu .zt-kbd`) i stoi skleiony: `⌘⇧C`.
